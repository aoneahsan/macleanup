# Composition and review rubric

## Ten compositions for a set (pick per post, never all the same)

1. **Screen hero**: a large real capture, cropped to the moment the post talks about, headline beside it.
2. **Phone + desktop pair**: the same feature on both, when the post is about responsiveness or the app view.
3. **Type poster**: one short line in the product's display face, huge, with the mark and one small capture chip.
4. **Detail crop**: a 2–3× zoom of one control or state, with a callout line in the product's accent.
5. **Before / after**: two real states side by side (empty → filled, problem → fixed), labelled in the product voice.
6. **Product art scene**: the product's own mascots or illustrations staging the idea; a capture sits in the scene.
7. **Steps strip**: 3 real captures in sequence with numbered chips in the product's chip style.
8. **Quote card**: a verified, attributed quote in the display face, the product's art in the margin.
9. **Data moment**: a real number from the product (count of tools, rounds, routes) taken from code, never invented.
10. **Behind the build**: a real code, schema or design-token excerpt styled in the product's palette.

Carousel decks reuse 2–3 of these across pages with one consistent frame per deck.

## Review rubric (score each card; ship only all-pass)

| Check | Pass |
|---|---|
| Product identity | Someone who uses the product recognises it without reading the name |
| Focal point | One element is clearly first; eye path ends at the CTA |
| Fit to post | The card says the same single idea as the post's hook |
| Real | Every screen is a capture of the live app; every fact traces to the repo |
| Typography | Product fonts, balanced wrap, no orphan word, ≥ 28 px text |
| CTA | Button-style action + main link, readable at phone feed size |
| Anti-AI | None of the checklist failures in SKILL.md |
| Variety | Composition differs from the set's other nine |
